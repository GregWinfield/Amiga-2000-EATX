# Zorro II expansion termination coupons

Three separate KiCad 10 projects exercise nine adjacent Zorro data paths. Each project has its own schematic and routed four-layer board. Building three separate boards avoids branch-selection jumpers and unused termination stubs. The design files and fabrication archives are for review. For a given signal, all three source-to-socket paths have identical drawn lengths. Across the nine lanes the range is 168.15–170.88 mm. T9/BD4 uses J1.18, J2.83 and the C9 private junction. A copies the R3.1 C672/R605F1 branch there. B routes that private node to RN1.10. The different B/C branch lengths let the fixture compare both package and practical routing effects. A matched-length package-only study would answer a different question. [Actual path lengths for each lane](lanes.csv)

## Assembly and fabrication review

- Open each project from this checkout. The common symbol library is one directory above the projects. A's local 0805 library captures Jason Beer's production lands. The coupon J2 uses production pad centres, with a local footprint adapted for the listed TE socket. The R3.1 shopping list identifies a TE card-edge socket although the historical library name says Samtec. TE specifies through-hole solder posts with board-retention features. Drawing C-5645235 Rev C1 calls for 1.02 ± 0.08 mm finished holes. R3.1 uses 0.80 mm at CN605. Coupon J2 uses 1.02 mm nominal holes and the original 1.31 mm lands at the original 2.54 mm pitch and 5.08 mm row spacing. The nominal radial annulus is 0.145 mm. A 1.60 mm trial land conflicted with twelve production trace clearances on A, so all coupons retain the R3.1 land diameter. Review the finished-hole, copper registration and remaining-ring tolerance with the fabricator. Keep the fixture on hold if the process cannot meet them. The component outline follows the TE body. Confirm drill compensation and finished-hole tolerance with the fabricator, then dry fit the retention posts and check row alignment. Confirm 1:1 fit before approving fabrication. [Production shopping list](../BOM/A2000EATX-REV31-ShoppingList.csv) · [TE connector and customer drawing](https://www.te.com/en/product-5645235-3.html)
- Each ZIP contains four Gerber copper layers, two mask layers, two silkscreen layers, Edge.Cuts, the Gerber job and metric Excellon drill. All drill features in these coupons are plated. The board centreline bounds are 223 × 149 mm with an L-shaped outline. Read the Gerber job and compare the submitted stack with the actual production build. Nominal order is F.Cu signal/GND, In1.Cu GND, In2.Cu external +5 V, B.Cu load/ground. Use 1.6 mm, green mask and white silk throughout. Confirm actual stack and impedance before comparing measurements.
- On each board J1 is the left header. J2 is the long socket. Facing the component side in PCB coordinates, C1 to C9 follow increasing Y in the branch bank. On A, resistor and capacitor rows lie alongside one another. On B, RN1 pin 1 is the return at the low-Y end, with pins 2–10 in lane order. On C the resistors form the outer row. CL1–CL9 are on the rear, alongside their socket contacts. Probe pads T1–T9 each have a ground pad just beside them. Use the KiCad F.Fab and B.Fab layers for exact reference placement. Use a passive termination card or the fixture load pads for the documented load sweep.
- KEMET's radial candidate has 2.54 mm lead pitch and a 3.81 × 2.54 mm maximum body plan. Check its formed leads in the 2.50 mm nominal footprint. Use the same measured capacitor lot for B and C. The 5.08 mm axial lead form and the shared SIP common impedance require physical verification. [KEMET specification](https://yageogroup.com/download/specsheet/C315C102J5G5TA) · [Vishay axial family](https://www.vishay.com/docs/28724/mrs16m25.pdf) · [Bourns SIP](https://bourns.com/docs/Product-Datasheets/4600x.pdf)

## Verification

KiCad 10.0.8 reported **zero ERC findings, zero DRC findings, zero unconnected pads and zero schematic parity differences** for each coupon. No rule exclusions were introduced. The independent check compares every schematic pin to its board pad, verifies all 27 lane paths and their private-node membership, and compares A's copper lengths with the stored R3.1 baseline to within 0.001 mm. Run `python coupon/verify.py` with KiCad's Python interpreter and CLI available. These checks cover connectivity and drawn geometry. Bench testing and factory stack confirmation are open.
