# Zorro II expansion termination coupons

Three separate KiCad 10 projects exercise nine adjacent Zorro data paths. Each project has its own schematic and routed four-layer board. Building three separate boards avoids branch-selection jumpers and unused termination stubs. The design files and fabrication archives are for review. [Assembly BOM](BOM.csv) · [Pin and length table](lanes.csv) · [Electrical acceptance plan](MEASUREMENT_PLAN.md)

For a given signal, all three source-to-socket paths have identical drawn lengths. Across the nine lanes the range is 168.26–171.00 mm. T9/BD4 uses J1.18, J2.83 and the C9 private junction. A retains the C672/R605F1 private branch there. B routes that private node to RN1.10. The different B/C branch lengths let the fixture compare both package and practical routing effects. A matched-length package-only study would answer a different question. [Actual path lengths for each lane](lanes.csv)

## Assembly and fabrication review

- Open each project from this checkout. The common symbol library is one directory above the projects. A's local 0805 library captures Jason Beer's production lands. J2 uses the TE 5645235-3 solder socket with the card datum held fixed. The two rows are 4.85 mm apart. All 100 holes are 1.02 mm finished, with 1.53 mm outer lands and 1.80 mm inner lands. Twelve of the electrical tails also provide retention. Fabrication requires the supplier and sample checks. [Connector resolution](CONNECTOR_RESOLUTION.md) · [Manufacturing status and equipment](FABRICATION_READINESS.md)
- Each ZIP contains four Gerber copper layers, two mask layers, two silkscreen layers, Edge.Cuts, the Gerber job and metric Excellon drill. All drill features in these coupons are plated. The board centreline bounds are 223 × 149 mm with an L-shaped outline. Read the Gerber job and compare the submitted stack with the actual production build. Nominal order is F.Cu signal/GND, In1.Cu GND, In2.Cu external +5 V, B.Cu load/ground. Use 1.6 mm, green mask and white silk throughout. Confirm actual stack and impedance before comparing measurements.
- On each board J1 is the left header. J2 is the long socket. Facing the component side in PCB coordinates, C1 to C9 follow increasing Y in the branch bank. On A, resistor and capacitor rows lie alongside one another. On B, RN1 pin 1 is the return at the low-Y end, with pins 2–10 in lane order. On C the resistors form the outer row. CL1–CL9 are on the rear, alongside their socket contacts. Probe pads T1–T9 each have a ground pad just beside them. Use the KiCad F.Fab and B.Fab layers for exact reference placement. Use a passive termination card or the fixture load pads for the documented load sweep.
- KEMET's radial candidate has 2.54 mm lead pitch and a 3.81 × 2.54 mm maximum body plan. Check its formed leads in the 2.50 mm nominal footprint. Use the same measured capacitor lot for B and C. The 5.08 mm axial lead form and the shared SIP common impedance require physical verification. [KEMET specification](https://yageogroup.com/download/specsheet/C315C102J5G5TA) · [Vishay axial family](https://www.vishay.com/docs/28724/mrs16m25.pdf) · [Bourns SIP](https://bourns.com/docs/Product-Datasheets/4600x.pdf)

## Verification

KiCad 10.0.8 reported **zero ERC findings, zero DRC findings, zero unconnected pads and zero schematic parity differences** for each coupon. No rule exclusions were introduced. The independent check compares every schematic pin to its board pad, verifies all 27 lane paths and their private-node membership, and checks all 100 socket positions and their four-layer lands, and compares A's routes with R3.1 (0.100 mm allowance for the modified escape, 0.001 mm for each private branch). Run `python coupon/verify.py` with KiCad's Python interpreter and CLI available. These checks cover connectivity and drawn geometry. Bench testing and factory stack confirmation are open.
